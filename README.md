# print – הדפסה עם קוד

אתר סטטי לגמרי (בלי שרת משלכם), שרץ בחינם על **GitHub Pages**, עם **Firebase** (תוכנית Spark החינמית, בלי כרטיס אשראי) לשמירת הקבצים והקודים.

| כתובת | מה יש שם |
|---|---|
| `/` | הזנת קוד. קוד של קובץ פותח מיד את חלונית ההדפסה של כרום. **קוד מאסטר** מציג כמה קבצים ממתינים בתור וכפתור "הדפסת כל התור": מדפיס אותם אחד אחרי השני ומנצל את הקוד של כל אחד מהם. |
| `/send` | העלאת קובץ (PDF, תמונה או טקסט, עד 15MB) וקבלת קוד של 6 ספרות: חד-פעמי ותקף לשעתיים. |
| `/admin` | כניסה עם Google (רק `rb077858@gmail.com`). לכל קובץ יש קוד אישי אחד, שאפשר לערוך (קוד מותאם, חד-פעמי או רב-פעמי, תוקף, חידוש). יש קוד מאסטר אחד בלי תוקף. אפשר גם להעלות קבצים, לחפש, לסנן ולנקות. |

**התור:** כל קובץ שהקוד שלו חד-פעמי, עוד לא נוצל ועוד לא פג.

## איך זה מאובטח בלי שרת

הכללים ב-`firestore.rules` אוכפים את הכול בצד של Firebase, לא רק בדפדפן:
- אי אפשר לראות את רשימת הקודים או הקבצים. אפשר רק לבדוק קוד מסוים.
- כדי לקרוא קובץ צריך לממש קוד. מימוש של קוד חד-פעמי מסמן אותו כמשומש באותה כתיבה, ונותן למשתמש הזה בלבד 10 דקות להוריד את הקבצים של הקוד.
- קוד שכבר נוצל או שפג תוקפו נדחה בשרת של Firebase.
- רק המנהל (אימייל מאומת `rb077858@gmail.com`) יכול לערוך, למחוק ולראות הכול.

הקבצים נשמרים בתוך Firestore בחתיכות, כי Firebase Storage כבר לא זמין בתוכנית החינמית.

## הקמה חד-פעמית (כ-10 דקות)

### 1. Firebase
1. נכנסים ל-https://console.firebase.google.com ויוצרים פרויקט חדש (אפשר לכבות את Google Analytics).
2. **Build → Authentication → Get started**. בלשונית Sign-in method מפעילים את **Anonymous** ואת **Google**.
3. באותו מסך, בלשונית **Settings → Authorized domains**, מוסיפים את `reembir.com` (וגם `rb077858.github.io`).
4. **Build → Firestore Database → Create database**: בוחרים מיקום (למשל `eur3`) ו-production mode.
5. בלשונית **Rules** של Firestore מוחקים את מה שיש, מדביקים את כל התוכן של `firestore.rules` ולוחצים **Publish**.
6. **Project settings** (גלגל השיניים) → **Your apps** → מוסיפים אפליקציית Web (`</>`), מעתיקים את אובייקט `firebaseConfig` ומדביקים את הערכים בקובץ `assets/firebase-config.js`.

### 2. GitHub Pages
1. ממזגים את הקוד לענף `main`.
2. ב-GitHub: **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, תיקייה `/ (root)`.
3. אחרי דקה-שתיים האתר זמין בכתובת `https://reembir.com/print/` (ובהתאמה `/print/send/` ו-`/print/admin/`).

> GitHub Pages חינמי רק למאגר **ציבורי**. זה בטוח: המפתחות ב-`firebase-config.js` ציבוריים מטבעם, והאבטחה נעשית בכללים. אם רוצים מאגר פרטי, אפשר לפרסם בחינם גם ב-Cloudflare Pages או ב-Netlify. מחברים אליהם את המאגר בלי שלב build, ומוסיפים את הדומיין שלהם ל-Authorized domains.

## מגבלות התוכנית החינמית
- Firestore: אחסון של 1GB, 50,000 קריאות ו-20,000 כתיבות ביום. זה מספיק להמון הדפסות. קובץ של 15MB הוא בערך 21 כתיבות.
- כדאי ללחוץ מדי פעם על "ניקוי" בדף הניהול. הכפתור מוחק קודים שפג תוקפם וקבצים מ-`/send` שכבר אין להם קוד פעיל.

## הערות
- ההדפסה פותחת את חלונית ההדפסה הרגילה של הדפדפן (נבדק בכרום). קובצי PDF מומרים לתמונות באיכות גבוהה לפני ההדפסה, כדי שבתור כל חלונית תיפתח רק אחרי שהקודמת נסגרה.
- סוגי קבצים נתמכים: PDF, תמונות וטקסט. קובצי Word וכדומה צריך לשמור קודם כ-PDF.
- קוד של 6 ספרות אפשר לנחש בעיקרון. ההגנה היא שהקודים קצרי-חיים וחד-פעמיים, ומכסת הקריאות היומית מגבילה ניסיונות ניחוש.
